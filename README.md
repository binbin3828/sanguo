# 三国霸业 · 策略复兴版

以步步高电子词典《三国霸业》为参考的手机优先浏览器单机策略游戏，目前处于可玩重构预览阶段。详细需求、原版对照来源和后续实施顺序见 [重构实施方案](docs/10-重构实施方案.md)。

## 运行

在项目目录运行：

```bash
npm run dev
```

然后打开 <http://localhost:8080/>。项目当前无需安装第三方依赖；`node server.js` 也可直接启动。

开发服务默认只监听本机。经授权需要用同一 Wi-Fi 的手机访问时，可以运行 `HOST=0.0.0.0 node server.js`，并打开终端输出的局域网地址。当前已按 320px 和 390px 手机视口重新设计；真机触控、字体和性能仍需在实际手机上检查。

## 当前可玩内容

- 四个历史剧本、38 座城池及各剧本的势力和武将数据。
- 战略地图、城池详情、相邻路线、武将选派、开垦、招商、治理、出巡、征兵、寻访、交易、输送和道具管理。
- 月末资源结算、电脑势力依各城需求下令与择机扩张，并生成可回看的「天下纪事」。
- 相邻城出征、9×7 战棋移动与攻击、胜负结算和撤军。
- 三个浏览器本地存档位，支持导出 JSON 文件与导入恢复；失去全部城池或统一现存势力时显示结局。

每名武将每月最多接一项任务。同一座城可为开垦、招商、治理、出巡、征兵或寻访勾选多名武将，一次为他们分别下令；费用按人数累计。治理提升防灾，出巡提升民忠与人口。征兵可以按民忠与现有金钱自选每名武将的兵量，默认填入当前人数和资金允许的最大值；每 10 兵花 1 金，征得的兵先进入城池后备兵。「军备 → 分配兵力」默认填入该武将目前可带的最大兵数，仍可手动调整；分配立即生效，不消耗本月行动。开垦、招商、治理、出巡、征兵在下令时生效；寻访与招降在结束本月时结算。攻城后参战守将可能成为俘虏，可从「人事 → 招降俘虏」选人招降。出征可选 1–3 名本月可用且已带兵的武将，战斗使用他们各自实际带兵数。手机战略阶段固定在一个主画面：38 城全景地图在中间，当前城池资源和指令入口在下方；点内政、人事、军备、外交后逐层选择指令、目标和武将。选城、城池详情、军情均由抽屉打开，地图无需缩放或拖动，主页面无需纵向滚动。战斗中点选蓝色部队，再点高亮格子移动或攻击；每支部队每回合行动一次。

开垦、招商、征兵、交易、侦察、宴请、处斩、流放及道具赏赐或没收后会显示结果。军备面板的「侦察」在地图选非己方城池、再选武将，即时查看城池和守将情报；「掠夺」在月末获取金粮，同时使本城民忠、农业、商业减半。人事面板点击「移动武将」后，直接在全景地图上点选发光的己方目的城，再选执行武将；武将连同带兵月末抵达。招降按俘虏性格、忠诚和双方智力判定。结束本月后，居中弹窗逐件播报城池易主、人才归附、缺粮和我方寻访、招降、输送、移动、掠夺回报；点击「下一件」继续，最后进入下月。寻访可能发现城中隐藏道具；进入「人事 → 道具」可查看、赏赐或没收，武将最多装备两件，兵符赏赐后立即使用。在「城池详情 → 驻城武将」点击武将，可查看基础属性、装备加成与每件装备的详情，并为己方可用武将分配兵力。电脑势力的普通政令不会播报。底部「军情」入口可重播最近 12 个月的月末纪事。

选将列表会把可接令武将排在前面，并按当前指令的实际效果推荐人选：开发、寻访、招降偏重智力，出征综合带兵和武力；治理、出巡、征兵的当前收益与武将属性无关，优先显示非专精武将。已行动、体力不足或未带兵者列在后面并显示原因。批量指令按推荐顺序执行；具体依据见 [手机端游戏主画面设计](docs/11-手机端体验重构.md)。

## 源码说明

当前网页入口在 `src/main.js`，现用规则在 `src/game/`。`data/dat.xml` 是剧本数据源。原有 `src/core`、`src/data`、`src/systems` 和 `src/ui` 是旧版开发内容，仍保留供规则对照，当前页面不调用它们。`PROGRESS.md` 的 100% 是旧版模块文件统计，并非游戏完成度。

武将接令、开发公式、寻访结算时机、征兵额度与费用、后备兵分配、体力规则已对照 [BGWP/iBaye](https://gitee.com/bgwp/iBaye) 的 C 语言源码；战斗、城市收支与 AI 仍采用预览规则，差异见 [武将指令规则对照](docs/12-武将指令规则对照.md)。旧版单存档会显示在存档 1，读取时迁移到新版兵力模型；旧存档中已行动的城池在迁移当月保持锁定，进入下一月后使用新规则。三个存档位使用浏览器 `localStorage`，清除站点数据仍会删除它们；请先导出 JSON 文件备份。微信小游戏发布需要另外适配其运行环境，当前版本是手机网页。
