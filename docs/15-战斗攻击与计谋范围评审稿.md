# 战斗攻击与计谋范围：评审与落地记录

> 2026-09-29。用户确认继续实施后，已接入明确的攻击按钮、范围高亮、目标预览和确认流程。战斗默认使用手机版范围，战场“更多”可切换到已解出的经典范围掩码。本文保留设计理由和范围对照。

## 1. 当前问题与原因

目前战场底部只有“计谋、待机、结束回合、撤军”，没有普通攻击按钮。普通攻击实际上绑定在“选中武将后直接点击射程内敌军”上，但界面没有让玩家进入攻击状态，也没有显示完整攻击覆盖范围。弓兵普通攻击设为距离 2–3 格，相邻敌军完全不能攻击。玩家很容易遇到“能选技能，却找不到普通攻击”的情况。

原 C 程序在 `FgtPkAi.c:FgtGetCmdRng` 中，把 6 种兵种的普通攻击范围分别读取为 5×5 掩码；每个技能另有 9×9 范围掩码。**原版精确数据现已解出**，见 [原版战斗范围资源解析](16-原版战斗范围资源解析.md)。本稿下方的距离、射线和兵种差异仍是手机新版的待评审提案，不是原版数值。

## 2. 操作流程

固定底栏改成 **移动、攻击、计谋、待机、结束回合**。撤军和存档放在战场顶部“更多”菜单，避免底栏过挤。

1. 点武将后默认显示可移动格；武将卡显示“普攻 1 格”等真实射程和可用计谋数量。
2. 点“攻击”后，地图画出该兵种攻击覆盖区。射程内且射线畅通的敌军高亮；被地形或单位挡住的敌军显示阻挡图标。即使当前没有目标，攻击按钮仍可点击查看覆盖区，并提示先移动或换将。
3. 点高亮敌军后显示简短预览：目标、预计损兵、目标地形防御、可能的反击。点“确认攻击”才扣除本回合主行动。取消预览回到攻击选目标状态。
4. 点“移动”返回可移动格。移动完成后保留主行动，默认进入攻击选目标状态；尚未攻击或施计时可撤回移动。
5. 点“计谋”打开技能层，每项显示目标类型、实效范围、MP、天气/地形限制和不可用原因。选择技能后地图显示该技能的覆盖区；点目标看效果预览，再确认施放。天变等无目标技能直接显示确认层。
6. 行动完成后本将灰化，可选择下一位尚未行动的武将。地图高亮与行动合法性都由同一个规则函数提供，界面不再自己推算距离。

## 3. 普通攻击范围提案（新版）

格数采用**曼哈顿距离**：上下左右相邻为 1 格，斜相邻为 2 格。城墙、山体或中间单位可阻断远程射线；近战不受射线影响。表内是允许点击的目标距离，不代表移动力。

| 兵种 | 普攻距离 | 特点 |
|---|---|---|
| 骑兵 | 1 格 | 贴身打击；强处仍在移动后冲锋 |
| 步兵 | 1 格 | 稳定近战与守线 |
| 弓兵 | 1–3 格 | 相邻仍可自卫，但相邻普攻伤害减 30%；2–3 格正常输出 |
| 水军 | 1 格；在河流/桥梁上为 1–2 格 | 水道拥有射程优势，陆地仍是近战 |
| 极兵 | 1 格；同行或同列的 2 格 | 体现长兵器穿刺，隔着单位仍会被阻挡 |
| 玄兵 | 1–2 格 | 基础伤害低，主要依靠计谋 |

这里建议弓兵可打相邻目标，解决当前“贴身完全无法攻击”的死区；减伤维持站位价值。**原版实际上仅允许弓兵普攻曼哈顿距离恰好 2 的目标**。因此需要在“保留经典盲区”与“采用新版近身自卫”之间评审，不应把 2–3 格误认作原版。

## 4. 技能范围提案（新版）

以下范围在技能选择层逐项展示；`0` 表示可对自己施放。“同行/同列”表示目标与施术者共享行或列。天气、地形、等级、MP 仍与范围并列校验。

| 技能 | 使用兵种 | 目标 | 范围 |
|---|---|---|---|
| 冲锋 | 骑兵 / 极兵 | 敌军 | 骑兵 1；极兵 1–2 且同行/同列。必须先移动 |
| 飞矢 | 弓兵 | 敌军 | 1–3；相邻效果较弱 |
| 箭雨 | 弓兵 | 敌军格及周围 | 2–3，中心格需射线畅通 |
| 火攻 | 弓兵 / 玄兵 | 敌军 | 弓兵 2–3；玄兵 1–2。雨与冰雹禁用 |
| 落石 | 步兵 / 玄兵 | 敌军 | 步兵 1；玄兵 1–2。施术者必须在山地 |
| 水淹 | 水军 / 玄兵 | 敌军 | 水军在河流/桥梁上 1–3，否则 1–2；玄兵 1–2 |
| 定身 | 玄兵 | 敌军 | 1–2 |
| 援兵 | 步兵 / 玄兵 | 友军或自己 | 步兵 0–1；玄兵 0–2 |
| 奇门 | 玄兵 | 友军或自己 | 0–2 |
| 天变 | 玄兵君主 | 全场天气 | 无目标；点确认后改变下回合天气 |

同名技能可因兵种不同而有不同射程，这是本次新版创新。原版 30 个技能范围块已提取到 [classic-battle-ranges.json](../data/classic-battle-ranges.json)；经典配置可以直接使用其中的掩码。例如原版飞矢、箭雨、火箭都是曼哈顿距离恰好 3 的外圈 12 格，并非此表所提的 2–3 格。

## 5. 规则与画面的一致性

- 普攻、技能各自使用一份 `getLegalTargets` 结果：高亮、预览和确认时都读取它，避免“亮了但点不了”。
- 远程被阻挡时，明确写“射线被山地/城池/部队挡住”，不只显示“超出范围”。
- 计谋列表同时显示“该武将的实际范围”，不能只显示技能表里的通用范围。
- 预览不消耗 MP、粮草和随机数；确认后才结算。待机或结束回合不会替玩家自动选攻击目标。
- 范围和伤害数值集中在战斗配置，兵种名 `水兵` 与 `水军` 的既有数据差异由战斗入口统一转换。

## 6. 本次准备修改的文件

- `src/game/BattleCore.js`：兵种普通攻击掩码/射程、技能按兵种射程、合法目标与阻挡原因。
- `src/game/GameModel.js`：攻击/计谋确认入口，统一校验并结算；保持“移动后还能下主命令”。
- `src/main.js`：五按钮底栏、攻击与技能选目标状态、预览确认层、范围提示。
- `styles.css`：攻击范围、技能范围、阻挡标识和 320px 宽手机布局。

当前落地选择：手机版允许弓兵相邻普攻并减伤 30%，攻击和计谋都采用“选目标→预览→确认”；经典范围保留原版弓兵距离 2 的盲区。普通攻击伤兵已按 iBaye `FgtCount.c` 计算；经典范围关闭手机版的概率反击。天气、桥梁、奇门和技能伤害仍采用本项目规则。
